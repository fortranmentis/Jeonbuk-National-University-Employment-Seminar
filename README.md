# 지구환경과학과 졸업 후, 데이터 엔지니어로 일하기

전북대학교 지구환경과학과 학부 3~4학년을 중심으로 준비한 취업·진로 세미나 웹 프레젠테이션입니다. 발표자: **이상학 · GeoSR Data Engineer**.

**[발표 열기](https://fortranmentis.github.io/Jeonbuk-National-University-Employment-Seminar/)** · [자료 출처](SOURCES.md)

발표 50분 + 질의응답 10분, 총 35개 화면입니다. 대학생활·복무·공동연구·인턴 경험, 회사와 담당 업무, 해양·기상 빅데이터 및 AIS, 채용·연봉·학습 환경, AI·개인 프로젝트와 학생의 다음 행동으로 이어집니다.

## 발표 방법

- **← / →, Space, Page Up / Down**: 화면 이동
- **Home / End**: 첫 화면 / 마지막 화면
- **G**: 목차, **N**: 발표자 메모, **F**: 전체화면
- **?**: 도움말, **Esc**: 열린 창·메모 닫기 또는 전체 읽기 종료
- 하단 타이머는 직접 시작·일시정지·초기화합니다. 발표 50분이 지나면 표시 색이 바뀝니다.
- 목차의 **전체 읽기**로 모든 화면을 연속해서 읽거나 **인쇄 / PDF**로 저장할 수 있습니다.
- 모바일은 세로 읽기·터치 이동을 지원하며, 실제 발표는 가로 화면을 권장합니다.

## 로컬 실행

외부 라이브러리·폰트·API 없이 동작하는 HTML/CSS/JavaScript입니다.

```sh
python3 -m http.server 8080
```

브라우저에서 `http://localhost:8080`을 엽니다. 폴더 전체를 내려받으면 사진과 발표 파일을 로컬에서 사용할 수 있습니다. 참고자료 링크는 인터넷 연결이 필요합니다. 최초 온라인 방문만으로 전체 오프라인 사용이 보장되는 방식은 아닙니다.

## 수정

- `slides.js`: 화면 제목·본문·발표 메모·권장 시간
- `style.css`: 발표·모바일·인쇄 레이아웃
- `app.js`: 이동·목차·메모·타이머·전체 읽기
- `assets/`: 제공 사진과 기존 공개 연구·앱 화면, 강연 링크 QR

회사소개서의 원본·추출 이미지는 포함하지 않습니다. 발표 자료의 개인 사진과 연구 그림은 각각의 출처·권리가 있으며, 소프트웨어 공개가 이미지 재사용 허가를 뜻하지 않습니다.

전형·연봉·출장 설명은 발표자 제공 안내입니다. 현재 채용 여부·보상 포함 항목·학위 지원 조건은 실제 공고와 회사 규정을 확인해야 합니다. 공동연구·회사 업무·개인 프로젝트를 구분하고, 과학적 정확도·실제 서비스 운영 성능을 과장하지 않습니다.
